# Domain-aware promoter prediction

CPU-first, leakage-aware PyTorch promoter pipeline with separate E. coli, B. subtilis, Archaea, Human, Mouse, and Arabidopsis models. Original data are never modified and CD-HIT is never rerun.

## Quick start

```bash
python -m pip install -r requirements.txt
python main.py audit --data-dir "data/3) finalized"
python main.py split
pytest -q
python main.py train --group ecoli --model multiscale_cnn
python main.py train --group bsubtilis --model multiscale_cnn
python main.py train --group archaea --model multiscale_cnn
python main.py train --group human --model residual_cnn
python main.py train --group mouse --model residual_cnn
python main.py train --group arabidopsis --model residual_cnn
```

Runs checkpoint every epoch and resumes automatically. Use three or five seeds only after validation screening.

```bash
nohup python main.py train --group archaea --model cnn_transformer > results/logs/archaea_cnn_transformer.log 2>&1 &
tmux new -s promoters
python main.py train --group human --model residual_cnn --seed 2026 --epochs 200
# Re-run the identical command to resume from latest.pt.
```

Screening produces validation predictions only. After model/configuration/threshold selection is frozen, run the selected command once with `--evaluate-test` for untouched-test evaluation. Do not use this flag during screening or optimization.

## Web predictor

The browser interface loads a validation-weighted hybrid of the three-seed CNN ensemble and a domain-specific 1–4-mer Random Forest. It falls back to the CNN ensemble when no hybrid artifact exists. The interface accepts either one DNA sequence or a FASTA file and returns per-sequence probabilities, a promoter/non-promoter pie chart, and a downloadable CSV.

```bash
python -m pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8000
```

Open `http://localhost:8000`. Interactive API documentation is at `http://localhost:8000/docs`.

### Deploy on Render

The repository includes a `render.yaml` Blueprint for a Python web service with a 2 GB instance,
which provides enough memory for PyTorch and a loaded three-seed ensemble. Commit the application
files and the selected `best_mcc.pt` checkpoints exposed by `.gitignore`, push the repository to
GitHub, and create a new Render Blueprint from that repository. Render installs `requirements.txt`,
starts `uvicorn app:app --host 0.0.0.0 --port $PORT`, and checks `/api/health` automatically.

The site provides single-sequence and FASTA upload prediction, Plotly output summaries, per-record
classification, and CSV download. A free 512 MB Render service might run out of memory while loading
the larger bacterial ensembles; use the configured `1c-2g` plan for reliable inference.

Retrain all hybrid models without touching the split definitions:

```bash
python -m scripts.ablate_features --group all --trees 50 --threads 4 --minimum-mcc-delta 0.002
python -m scripts.train_hybrid_ensemble --group all --trees 500 --threads 4
```

Feature ablation is validation-only and organism-specific. It compares the legacy 1–4-mer baseline (with the constant N-ratio removed), canonical reverse-complement-collapsed 1–6-mers, promoter-position windows, and dinucleotide stability features. Only blocks improving validation MCC by at least 0.002 are enabled for final hybrid training.

## Scientific status

The audit and deterministic organism-stratified split are generated by `audit`. Six archaeal cross-label reverse-complement groups are quarantined. Bacteria and Eukaryota are modeled per organism; domain-level report metrics are test-count-weighted averages of organism results. Training outputs are not claimed until their checkpoints, predictions, and metrics exist.
