# Domain-aware promoter prediction

CPU-first, leakage-aware PyTorch research pipeline for the finalized Bacteria, Archaea, and Eukaryota FASTA datasets. Original data are never modified and CD-HIT is never rerun.

## Quick start

```bash
python -m pip install -r requirements.txt
python main.py audit --data-dir "data/3) finalized"
python main.py split
pytest -q
python main.py train --domain bacteria --model residual_cnn
python main.py train --domain bacteria --model multiscale_cnn
python main.py train --domain bacteria --model cnn_bilstm
python main.py train --domain bacteria --model cnn_transformer
python main.py train --domain bacteria --model domain_aware
python main.py train --domain unified --model domain_aware
```

Repeat screening for `archaea` and `eukaryota`. Runs checkpoint every epoch and resume automatically. Use three or five seeds only after validation screening.

```bash
nohup python main.py train --domain archaea --model cnn_transformer > results/logs/archaea_cnn_transformer.log 2>&1 &
tmux new -s promoters
python main.py train --domain eukaryota --model multiscale_cnn --seed 2026 --epochs 200
# Re-run the identical command to resume from latest.pt.
```

Screening produces validation predictions only. After model/configuration/threshold selection is frozen, run the selected command once with `--evaluate-test` for untouched-test evaluation. Do not use this flag during screening or optimization.

## Scientific status

The audit and deterministic split are generated by `audit`. Six archaeal cross-label reverse-complement groups are quarantined. Training outputs are not claimed until their checkpoints, predictions, and metrics exist. The five implemented architectures are: residual CNN, multi-scale CNN, CNN-BiLSTM, CNN-Transformer, and the proposed domain-aware multi-scale CNN-Transformer.
